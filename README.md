# SpotifyDapper

SpotifyDapper is an application developed using ASP.NET Core 6.0. This project enables querying statistics and performing data analysis from a SQL database containing 1 million song records using Dapper ORM (Object-Relational Mapper). The application provides search capabilities by singer name, release date, song title, and genre. Data is managed and transferred using DTOs (Data Transfer Objects).

## Project Overview

👤 **Interface**: Offers a user-friendly interface. Users can search Spotify data and view various statistics.

## Technologies and Tools Used

- 🤖 **.NET Core 6.0**: Used as the main framework for the web application. ✅  
- 🔄 **Dapper ORM**: Used as a lightweight and fast ORM solution for database operations. ✅  
- 📊 **Data Analysis**: Performed statistics on 1 million songs, allowing searches by singer name, release date, song title, and genre. ✅  
- 📋 **DTO (Data Transfer Objects)**: Used to securely and efficiently transfer data. ✅  

## SOLID Principles

The project has been developed in accordance with SOLID principles.

# SpotifyDapper

SpotifyDapper, ASP.NET Core 6.0 kullanılarak geliştirilmiş bir uygulamadır.
